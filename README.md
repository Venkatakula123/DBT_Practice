# DBT_Practice Commands

dbt debug --> used for checking the all connections like Snowflake and git repositories etc..

dbt init

dbt run => it will run all the dbt models present in your project

dbt run -m <model name> => to run specific model in dbt core or cloud

How to run seeds in DBT 
DBT Seed -m <seed_name >

dbt seed -m customer

dbt seed --full-refresh -m customer
